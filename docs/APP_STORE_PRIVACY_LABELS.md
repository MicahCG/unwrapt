# App Privacy (App Store Connect) — Unwrapt

Use these answers when filling Privacy Nutrition Labels.

## Data collected

### Contact Info
- **Email Address** — collected, linked to identity, used for App Functionality / Account Management. Not used for tracking.
- **Name** — collected, linked to identity, used for App Functionality. Not used for tracking.

### Purchases
- **Purchase History** — collected (VIP subscription via Apple; gift purchases), linked to identity, App Functionality / Analytics (optional). Not used for tracking unless you enable ad SDKs (we do not).

### User Content
- **Other User Content** — recipient names, occasions, interests, notes. Linked to identity. App Functionality.

### Contacts
- **Contacts** — only when the user chooses "iPhone Contacts": the app reads names and birthdays on the device, and only the people the user picks in the review (name, birthday) are sent and saved as recipients. Linked to identity. App Functionality. Not used for tracking. Apple Calendar reading works the same way (event titles and dates, read on device; only chosen people are saved).

### Identifiers
- **User ID** — Supabase auth user id. Linked. App Functionality.

### Usage Data
- **Product Interaction** — optional product analytics events. Linked. Analytics / App Functionality. Not used for tracking (no cross-app advertising).

## Data not collected
- Precise location, Health, the full Contacts address book or calendar (never uploaded; only people the user selects are saved), browsing history, search history (beyond in-app gift search which is User Content / Usage).

## Tracking
**No** — do not declare tracking unless you later add ATT / advertising SDKs.
