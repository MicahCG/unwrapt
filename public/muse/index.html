Unwrapt for Muse

Unwrapt is a personal gifting concierge. Muse can use this connector to remember people and occasions, recommend priced gifts, and create proposals that never purchase until the user approves.

Base URL
https://zxsswxzpzjimrrpcrrto.supabase.co/functions/v1/muse-api

OpenAPI: /muse/openapi.json

Authentication

  • Connector key (required): header X-Unwrapt-Api-Key: <key>
  • User scope (production): Authorization: Bearer <supabase_user_jwt> (OAuth / Google via Unwrapt)
  • Meta review sandbox: send X-Unwrapt-Review-User: 1 with the connector key to use the review account

Core endpoints

  • GET /health - public health
  • POST /v1/recommendations - 2-3 gift ideas with prices (no purchase)
  • GET /v1/recipients · POST /v1/recipients - people
  • GET /v1/occasions/upcoming - birthdays / anniversaries
  • POST /v1/gifts/proposals - save a proposal; approval required before charge

Example: recommend gifts

curl -X POST "$BASE/v1/recommendations" \
  -H "Content-Type: application/json" \
  -H "X-Unwrapt-Api-Key: $MUSE_CONNECTOR_KEY" \
  -d '{
    "recipient_name": "Mom",
    "budget_max": 75,
    "interests": ["gardening", "tea"],
    "occasion": "Birthday"
  }'

Access requirements

  • Users: Unwrapt account (Google sign-in) or Meta review sandbox account
  • Region: US-first for Muse review; product available on web at app.unwrapt.io
  • Payments: Stripe (Link / Checkout). Connector never auto-charges.
  • Rate limits: fair-use; recommend ≤ 60 requests/minute per connector key during review
